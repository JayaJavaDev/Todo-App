# Todo-App

A modern and responsive Todo Application built using React and Vite.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as Completed or Not Completed
- Filter tasks by status
- Responsive user interface
- Premium UI design

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## Run Locally

```bash
npm install
npm run dev
```

## Project

React Todo App with CRUD Operations.
